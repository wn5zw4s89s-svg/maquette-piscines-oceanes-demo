# Maquette de démonstration, Piscines Océanes

Maquette **non officielle**, réalisée par Joseph Leopold. Ce n'est pas le site de l'entreprise Piscines Océanes, qui ne l'a pas commandée.

- Bandeau visible en haut de chaque page.
- Balise `noindex, nofollow, noarchive` sur chaque page. (Le `robots.txt` de ce dossier est indicatif : un robots.txt n'est lu qu'à la racine du domaine.)
- Aucun cookie, aucune mesure d'audience, aucun formulaire.
- Aucune photo de Piscines Océanes. Cinq photos sous licence Unsplash, auteurs et liens dans `mentions.html`.
- Avis et note lus sur la fiche Google publique le 11/11/2026.
